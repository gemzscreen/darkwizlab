Method statement

These are vibe coded: I describe the job, an AI writes the code, and I check the output the way I'd check a calculation sheet before it goes out. Every app goes through the same four steps.

Start from a site problem

Each app begins with a task that was eating hours on a real project: a BOQ, a supplier chase, a code check, or a sign in a language I couldn't read.

Build it with AI

Written with Claude, usually as one self-contained page. There's no framework to maintain, and most of them keep working offline once loaded.

Check it like a calc sheet

Automated browser sweeps across the input combinations, then spot checks against hand calculations before anything is called finished.

Issue and revise

Published on GitHub Pages. When site use turns up a problem, it gets a revision, a version number and a changelog entry.

Who builds these

One civil engineer with more than 15 years in estimating, site supervision and project management, now working in quantity surveying. These apps exist because the tools I needed either didn't exist or didn't follow Philippine and regional standards.
